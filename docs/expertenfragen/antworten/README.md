# Antworten

Je Antwort eine Datei, benannt nach Datum und Einrichtung, z. B.
`2026-12-03-dwd.md`. Inhalt:

- Datum, Name und Einrichtung
- Welche Fragen (Nummern aus dem Fragenkatalog)
- Die Antwort im Wortlaut oder zusammengefasst
- Was wir daraufhin im Modell geändert haben
- Dürfen wir namentlich zitieren? (ja / nein / noch nicht gefragt)
